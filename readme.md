# Instruções de Visualização e Execução

Pré-requisitos

Um navegador web moderno (Chrome, Firefox, Edge, Safari).

Extension Live Server no VS Code (recomendada para testes locais).

Passo a Passo

# Clonar o repositório:

git clone https://github.com/seu-usuario/seu-repositorio.git


# Navegar até a pasta do projeto:

cd seu-repositorio


# Executar a aplicação:

Forma direta: Abra o arquivo index.html em seu navegador.

Servidor local (recomendado): Clique com o botão direito no index.html no VS Code e selecione "Open with Live Server".
